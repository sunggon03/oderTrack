# 주점 QR 주문 사이트 설치 안내

손님 → 주문 → (송금) → 카운터에서 입금 확인 → 주방에 주문서가 뜨는 흐름이에요.

| 화면 | 주소 | 누가 |
|---|---|---|
| 손님 주문 | `.../index.html` (모든 테이블 공용 QR 1개) | 손님, 로그인 없음 |
| 카운터 | `.../counter.html` | 직원, 로그인 + 직원 등록 필요 |
| 주방 | `.../kitchen.html` | 주방, 로그인 + 직원 등록 필요 |

## 0. 이미 설치했다면: 이번 버전으로 올리는 순서
1. GitHub 저장소에 이 폴더의 파일을 전부 다시 올려 덮어써요 (`fonts` 폴더는 그대로 둬도 돼요).
2. Firebase 콘솔 > Realtime Database > **규칙** 탭에 `database.rules.json` 내용을 통째로 붙여넣고 **게시**.
3. `.../counter.html`에 로그인해요. 규칙에 내 UID가 적혀 있으면 바로 열려요. "직원으로 등록되지 않은 계정이에요"가 나오면 위 "직원 등록"을 해요.
4. 올린 직후에는 예전 파일이 최대 10분쯤 남아 보일 수 있어요. 이상하면 새로고침하거나 잠시 뒤에 다시 열어요.

순서가 바뀌어도 사이트가 망가지지는 않아요. 규칙을 안 바꾼 채로 카운터를 열면 화면 위에 "보안 규칙이 예전 버전이에요" 경고가 떠요.

## 1. Firebase 만들기 (무료, 약 10분)
1. https://console.firebase.google.com 에서 프로젝트 추가. 애널리틱스는 꺼도 돼요.
2. 왼쪽 **빌드 > Realtime Database > 데이터베이스 만들기**. 위치는 가까운 곳(싱가포르 등), 모드는 **잠금 모드**로 시작.
3. **규칙** 탭에 `database.rules.json` 내용을 통째로 붙여넣고 **게시**.
4. **빌드 > Authentication > 시작하기 > 이메일/비밀번호 사용 설정**.
5. Authentication의 **사용자** 탭에서 직원 계정 1개 추가 (예: staff@example.com + 비밀번호). 카운터와 주방이 같이 써요.
6. **프로젝트 설정(톱니바퀴) > 내 앱 > 웹 앱(</>) 추가**. 나오는 설정 값을 `firebase-config.js`에 붙여넣어요. `databaseURL`이 안 보이면 Realtime Database 화면 맨 위 주소(https://…firebasedatabase.app)를 넣으세요.

### 직원 등록
Firebase는 누구나 새 계정을 만들 수 있어요. 그래서 "로그인했다"만으로는 직원으로 인정하지 않고, **직원으로 등록된 계정(UID)만** 주문을 보고 계좌·메뉴를 바꿀 수 있어요. 등록 방법은 두 가지이고 둘 다 동시에 쓸 수 있어요.

1. **규칙에 UID 직접 적기(기본)**: `database.rules.json` 안의 `auth.uid === '...'` 부분이 직원 UID예요. 붙여넣기만 하면 되고, 직원을 늘릴 때는 UID를 알려서 규칙 파일을 다시 만들어 게시해요.
2. **콘솔 데이터에 추가**: Realtime Database > **데이터** 탭에서 키 `staff` 아래에 UID를 키, 값 `true`로 추가해요. 5초 안에 화면이 자동으로 넘어가요.

등록 안 된 계정으로 로그인하면 "직원으로 등록되지 않은 계정이에요" 화면과 **내 UID**가 나와요. **UID 복사**를 눌러 복사한 값을 쓰세요(0과 O, 소문자 l과 대문자 I는 눈으로 읽으면 헷갈려요).

## 2. GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만들어요 (무료 Pages는 공개 저장소).
2. 이 폴더의 파일을 **`fonts` 폴더까지** 전부 올려요 (`README.md`, `database.rules.json`은 안 올려도 돼요). `fonts` 폴더가 빠지면 픽셀 글꼴이 안 나와요.
3. 저장소 **Settings > Pages > Branch: main / (root) > Save**. 1~2분 뒤 `https://계정.github.io/저장소/` 가 열려요.

## 3. 첫 설정
1. `.../counter.html` 로 로그인해요. 등록 안 된 계정이면 위의 "직원 등록"을 해요.
2. **메뉴·계좌** 탭: 주점 이름, 테이블 수, 계좌, 메뉴를 입력하고 **저장**. (비어 있으면 예시 메뉴 넣기 버튼이 있어요.)
3. **QR** 탭: 공용 QR 1개를 인쇄해 모든 테이블에 붙여요. 손님은 테이블을 고르지 않고 **입금자명과 인원수**만 입력해요. 테이블 번호는 **카운터에서 "입금 확인"을 누르기 전에 직원이 입력**해요(비워 두면 확인이 안 돼요). 포장이면 칸에 "포장"이라고 적으세요. 입력한 테이블과 인원수는 주방 주문서에 같이 떠요.
4. (선택) **송금 앱 링크**: 메뉴·계좌 탭의 "토스 송금 링크"·"카카오페이 송금 링크"에 계좌 주인이 앱에서 만든 본인 링크를 붙여넣으면 손님 화면에 "토스로 송금"·"카카오페이로 송금" 버튼이 생겨요. 토스는 `https://toss.me/아이디` 형태면 금액이 자동으로 이어 붙고, 카카오페이는 링크만 열려서 금액은 손님이 입력해야 할 수 있어요. **저장 전에 폰에서 직접 눌러 열리는지, 금액이 맞게 들어가는지 꼭 확인하세요.** 비워 두면 버튼 없이 계좌·금액 복사만 쓰여요.
5. 주방 태블릿에서 `.../kitchen.html` 로그인.

## 4. 오픈 전 점검 (꼭, 실제 주소에서)
아래를 폰 1대 + 카운터 + 주방 화면으로 한 번씩 해 보세요.

- [ ] 폰으로 QR을 찍어 입금자명·인원수를 넣고 주문 → 송금 안내(계좌·금액)가 나온다
- [ ] 카운터 카드에 입금자명·인원수가 뜨고, 테이블을 비운 채 "입금 확인"을 누르면 막힌다. 테이블을 적으면 주방에 "N번 · 이름 · N명"으로 뜬다
- [ ] (송금 링크를 넣었다면) "토스로 송금"·"카카오페이로 송금"이 폰에서 열리고 금액이 맞는지 확인한다
- [ ] 카운터 "입금 확인" 탭에 그 주문이 뜬다 (주방에는 아직 안 뜬다)
- [ ] "입금 확인 → 주방으로"를 누르면 주방에 주문서가 뜨고, 폰이 "주방 접수 · 주문번호 N번"으로 바뀐다
- [ ] 주방에서 "조리 완료"를 눌러도 폰 화면은 "주방 접수" 그대로다
- [ ] 메뉴·계좌 탭에서 품절을 체크하면 폰 메뉴에 바로 "품절"이 뜬다
- [ ] 태블릿의 와이파이를 껐다 켠다 → 빨간 "연결 끊김" 배너가 떴다가 사라진다
- [ ] 정산 > 주문 모두 지우기 → 주문이 지워지고, 폰의 "내 주문" 화면도 메뉴로 돌아간다
- [ ] 현장 와이파이/데이터에서 같은 순서로 한 번 더

종이 메뉴판과 수기 주문 용지를 준비하세요. 인터넷이 끊기면 주문이 멈춰요.
영업이 끝나면 **정산 > 주문 모두 지우기**로 다음 날 1번부터 시작해요.

## 화면에 뜨는 경고
- **빨간 "연결 끊김" 배너**: 서버와 연결이 끊겼을 때 떠요. 직원 화면은 경고음(낮은 소리 3번)과 끊긴 시간도 같이 나와요. 다시 연결되면 저절로 사라지고, 끊긴 동안 누른 주문·입금 확인은 연결되면 자동으로 전송돼요.
  - 직원 화면은 20초마다 서버 응답을 확인해요. 공유기는 켜져 있는데 인터넷만 죽은 경우도 30초 안에 알아채요.
  - 배너가 2~3분 넘게 안 사라지면 종이 주문으로 넘어가세요.
- **입금 대기 5분 넘음**: 카운터의 입금 대기 주문이 5분을 넘으면 카드가 빨갛게 바뀌고 한 번 소리가 나요. 은행 알림을 다시 확인하고, 입금이 없으면 테이블에 물어본 뒤 취소하세요. (기준 시간은 `counter.js` 맨 위 `UNPAID_WARN_MIN` 숫자예요.)
- **"보안 규칙이 예전 버전이에요"**: 새 `database.rules.json`을 게시하지 않았다는 뜻이에요. 0번의 2를 하세요.

## 알아둘 점
- 누구나 주문을 보낼 수는 있지만, 입금 확인 전에는 주방에 보이지 않아요. 장난 주문은 카운터에서 취소하세요. 장난 주문이 쏟아지는 것 자체는 막을 수 없어요(그때는 종이 주문으로 전환).
- 주문은 메뉴에 실제로 있는 품목·가격·이름일 때만 접수돼요. 수량은 1~99, 인원수는 1~99, 한 번에 30가지·50만원까지예요.
- 규칙(`database.rules.json`)을 바꾼 버전이라 **새 규칙을 게시하지 않으면 인원수가 포함된 주문이 거부돼요.** 파일을 올린 뒤 규칙도 꼭 다시 게시하세요.
- 카운터의 받을 금액은 손님이 보낸 값이 아니라 현재 메뉴 가격으로 다시 계산해요.
- 손님 화면은 다른 앱으로 넘어가 있거나 "주방 접수"까지 끝나면 서버 연결을 놓아요. 무료 요금제의 동시 접속 한도(100대)를 아끼기 위해서예요. 그래서 "주방 접수" 뒤에 카운터에서 주문을 되돌려도 손님 화면은 새로고침 전까지 그대로예요.
- 카운터·주방 화면은 꺼지지 않게 요청하지만(지원하는 브라우저만), 태블릿의 **자동 잠금도 꺼 두세요**. 알림음은 화면을 한 번 터치해야 켜져요.
- 계좌번호와 예금주는 손님 화면에 공개돼요. 직원 계정 비밀번호는 카운터·주방 담당만 알게 하세요.
- 파일을 더블클릭해서 열면 동작하지 않아요. 반드시 https 주소로 여세요.
